# My-shopping-
Global Shop - Multi-Language E-commerce Website built with HTML, CSS, JavaScript. Supports 6 languages and multiple currencies. Perfect for global customers.

## Jarvis (Android voice agent)

The `jarvis/` folder contains **Jarvis**, an Android (Kotlin) voice agent that operates the phone by voice in
Urdu, Roman Urdu and English. See [`jarvis/README.md`](jarvis/README.md) (Roman Urdu).
